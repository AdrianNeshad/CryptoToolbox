Addresses

  • Bitcoin - Legacy, P2SH, SegWit, Taproot (mainnet & testnet)
  • Litecoin, Dogecoin, Dash, Zcash (transparent)
  • Ethereum / EVM (EIP-55 checksum)
  • Tron, XRP (Ripple), Bitcoin Cash
  • Monero (keccak), TON (CRC16)
  • Cosmos chains (bech32), Solana (no checksum)

Keys

  • WIF private keys
  • Extended keys (xpub / xprv / zpub…)
  • BIP38-encrypted keys
  • Public keys (secp256k1, on the curve)
  • Possible private keys (hex, secp256k1 range)
  • PEM blocks - keys & certificates (DER)

Seed & entropy

  • BIP39 mnemonic (English, checksum)
  • Electrum seed phrases (standard, SegWit, 2FA)
  • Monero polyseed (16 words, checksum)
  • Phrases one word per line or next to labels
  • BIP32 derivation paths
  • Entropy, 16/32 bytes (hex, decimal, JSON)

Crypto metadata

  • Ethereum Keystore V3
  • JSON keystore fields (cipher, kdf, iv, salt, mac, ciphertext)
  • Algorithms - AES, ChaCha20, Argon2, scrypt, PBKDF2, SHA, HMAC, Ed25519, and more.

Format & encoding

  • JSON, also inside logs and other text
  • JWT (header decoded)
  • Base64 / Base64url (decoded), Base58, Hex
  • Hashes by length - MD5, SHA-1/224/256/384/512, RIPEMD-160, tx hashes
  • UUID (v1-v8, structure)
  • Values inside URLs and key=value pairs

BIP32 Derivation

Paste an extended key (xpub, ypub, zpub…) and a derivation path to preview the resulting Bitcoin addresses — Legacy, Nested SegWit and Native SegWit. Everything is computed locally in this window; nothing is sent online. Handy for sanity-checking a key after a successful unlock.

1 Extended key

An extended public key (xpub/ypub/zpub, or tpub/upub/vpub for testnet) or an extended private key (xprv/zprv…)

2 Derivation path

Relative to the key you pasted, e.g. 0/0 for the first receive address. You can also paste a full path like m/44'/0'/0'/0/0 — the hardened account prefix is ignored, since an extended public key can only derive non-hardened children. The last number is the start index.

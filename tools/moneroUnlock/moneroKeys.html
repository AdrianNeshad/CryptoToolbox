Monero .keys Unlock

Dictionary attack that unlocks a Monero .keys file and extracts the seed phrase and keys — everything runs locally on your computer.

.keys files created by Cake Wallet are supported too — enable Cake Wallet under Advanced and supply the wallet salt, short key and the encrypted wallet password.

Cake Wallet does not use a typed password. Instead it stores a random password, AES-encrypted, in the device keychain. Provide the two secret constants (wallet salt + short key) and that wallet's encrypted password to unlock the file. All values stay on your computer.

Short key + wallet salt together form the AES key (must total 16, 24 or 32 characters).

Turns the encrypted password into the plaintext wallet password using only the short key and wallet salt — no .keys file needed.

PIN code (optional)

Recover the wallet PIN from the PIN secret and the encrypted PIN password. This is standalone — click Decode PIN to decode it on its own, with no .keys file or wallet unlock needed. It is also included automatically when you run a full unlock.

Each password requires a CryptoNight computation (~0.5–1 s per password). Monero is deliberately slow to brute-force, so long lists take time. Your computer may feel sluggish while it runs.

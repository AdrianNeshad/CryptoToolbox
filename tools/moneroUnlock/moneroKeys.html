Paste one password per line, or load a .txt file.

Custom mode does not use a typed password. Instead the wallet stores a random password, AES-encrypted, in the device keychain. Provide the two secret constants (wallet salt + short key) and that wallet's encrypted password to unlock the file. All values stay on your computer.

Almost always 1. Only change if the wallet was created with --kdf-rounds N.

Turns the encrypted password into the plaintext wallet password using only the short key and wallet salt — no .keys file needed.

PIN code (optional)

Recover the wallet PIN from the PIN secret and the encrypted PIN password. This is standalone — click Decode PIN to decode it on its own, with no .keys file or wallet unlock needed. It is also included automatically when you run a full unlock.

Each password requires a CryptoNight computation (~0.5–1 s per password). Monero is deliberately slow to brute-force, so long lists take time. Your computer may feel sluggish while it runs.

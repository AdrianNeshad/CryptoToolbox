Monero .keys Unlock

Dictionary attack that unlocks a Monero .keys file and extracts the seed phrase and keys — everything runs locally on your computer.

.keys files created by Cake Wallet are currently not supported.

1 Choose .keys file

Found where you saved the wallet (Monero GUI/CLI), or in Monero/wallets/.

Paste one password per line, or load a .txt file.

Advanced

Almost always 1. Only change if the wallet was created with--kdf-rounds N.

Controls the address prefix. Auto uses the field in the file.

Each password requires a CryptoNight computation (~0.5–1 s per password). Monero is deliberately slow to brute-force, so long lists take time. Your computer may feel sluggish while it runs.

Epoch reference

  • Unix — seconds (or sub-units) since 1970-01-01 UTC
  • Apple Cocoa / NSDate — seconds since 2001-01-01 UTC (common in iOS SQLite)
  • WebKit / Chrome — microseconds since 1601-01-01 UTC
  • Windows FILETIME — 100-nanosecond units since 1601-01-01 UTC

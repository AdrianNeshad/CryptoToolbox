DeFiChain Wallet Unlock

Recovers the 6-digit passcode of a DeFiChain Light Wallet blob (@defichain/jellyfish-wallet-encrypted) and extracts the seed phrase or root private key. The whole 000000–999999 range is swept automatically — everything runs locally on your computer.

1 Paste encrypted data

Paste EITHER the raw encode() hex string (mnemonic scheme) OR the whole wallet JSON ({ raw: { encryptedPrivKey … } }). The shape is auto-detected.

2 Options

The defaults are fine for a normal DeFiChain Light Wallet. Use Both if you pasted a bare wallet key as raw hex and auto-detection guesses wrong.

Scheme

Will sweep 000000 … 999999 (1 000 000 codes).

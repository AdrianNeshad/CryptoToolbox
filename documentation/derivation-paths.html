Derivation Paths

HD derivation paths, SLIP-44 coin types, extended-key and address prefixes for common chains, and which wallets use which variant. Every row says how it was checked; the test vectors use the standard abandon abandon … about mnemonic with no passphrase.

Path anatomy

BIP-32 defines the tree, BIP-43 the purpose field and BIP-44 the five levels below. In this page x stands for the account number and i for the address index.

m / purpose' / coin_type' / account' / change / address_index

m

Master key: HMAC-SHA512 of the 64-byte BIP-39 seed with key "Bitcoin seed" (secp256k1) or "ed25519 seed" (SLIP-10 ed25519).

purpose'

Which standard / script type: 44 legacy, 49 nested SegWit, 84 native SegWit, 86 Taproot, 45 and 48 multisig, 1852 Cardano. Always hardened.

coin_type'

Chain, from the SLIP-0044 registry (0 Bitcoin, 60 Ether, 501 Solana…). 1' is testnet for all coins. Always hardened.

account'

Separate accounts (“portfolios”) under one seed, numbered from 0. Hardened, so an account xpub cannot reach other accounts.

change

0 external chain (receive addresses), 1 internal chain (change). Non-hardened in BIP-44, so an account xpub can derive all addresses. Cardano adds 2 = staking key.

address_index

Sequential address number from 0. Wallets stop scanning after a gap of unused addresses (BIP-44 gap limit: 20).

Hardened notation

' (or h) means index + 231: 44' = 0x8000002C. Hardened children need the parent private key; non-hardened ones can be derived from the parent public key.

ed25519 chains

SLIP-10 ed25519 supports hardened derivation only, which is why Solana, Stellar, NEAR, Sui, Aptos and Tezos paths are hardened at every level. Paths with non-hardened ed25519 levels are wallet-specific schemes.

Electrum seeds

Electrum 2.0+ does not generate BIP-39 phrases. The words are hashed directly; the seed type is the hex prefix of HMAC-SHA512(key = "Seed version", msg = phrase), and the BIP-32 root comes from PBKDF2-HMAC-SHA512(phrase, "electrum" + passphrase, 2048) — note the salt is electrum, not BIP-39's mnemonic.
